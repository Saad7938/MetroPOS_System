 Metro POS System  
A fully functional **Point-of-Sale (POS)** application built using **Java** and **Java Swing**, designed for supermarket / super store environments.  
Developed by **Muhammad Saad**.


  Overview  
Metro POS System is a desktop application created for retail stores and supermarkets to streamline:

- Billing  
- Inventory management  
- Product handling  
- Cashier operations  
- Invoice generation  
- Admin control  

The system uses Java Swing for GUI and supports clean & simple workflows suitable for real-world retail environments.

---

 Features  
 Sales / Billing  
- Add items to cart  
- Auto-price & total calculation  
- Quantity updates  
- Final invoice generation  

 Inventory & Products  
- Add new products  
- Update existing products  
- Manage categories  
- Track stock quantity  

 User Management  
- Admin login  
- Cashier login  
- Role-based access  

Receipt / Invoice  
- Auto-generated invoice number  
- Shows transaction details  
- Printable layout  

 UI & Experience  
- Java Swing based  
- Easy navigation  
- Error validation & alerts
